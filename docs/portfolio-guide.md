# Portfolio Guide

This project demonstrates the translation of proposal-domain expertise into a governed AI application.

## Five-minute evaluation path

1. Review the workflow and technical diagrams in the root README.
2. Read the control boundaries in [architecture.md](architecture.md).
3. Review the behavior-driven evidence in [regression-testing.md](regression-testing.md).
4. Compare the implemented capabilities against the roadmap.
5. Inspect the application demonstration and source code as they are released publicly.

## Core engineering claim

RFP Engine does not assume fluent model output is trustworthy. It creates a controlled environment in which model output can be validated, versioned, reviewed, corrected, approved, rejected, and traced to source material.

## Project boundary

The workflow concept draws on professional experience managing complex RFx responses. This portfolio is an independent project. It excludes employer intellectual property, submitted proposals, customer artifacts, confidential pricing, real credentials, and restricted solicitation files.
